## v2.8 Yenilikleri — Sıralama Sorusu

### Yeni Soru Tipi: 🔀 Sıralama
Seçenekleri doğru sıraya diz!

### Editör
- Soru tipi: 🔀 Sıralama seç
- Şıklar eklenir, eklenme sırası = doğru sıra
- Sıra numaraları gösterilir (1, 2, 3...)
- "Doğru şık" seçimi yoktur

### Telefon — Tap-to-Order
- Şıklar karıştırılmış gösterilir
- Tıklama sırasına göre 1, 2, 3... atanır
- Yanlış tıklandıysa tekrar tıklayınca geri alınır
- Tümü seçilince "SIRALI GÖNDER" aktif olur
- Sonuçta her şık için ✓ veya "Sen: X" gösterilir

### Projeksiyon
- Şıklar karıştırılmış "?" ile gösterilir
- Reveal sonrası 1-2-3... sırasıyla animasyonlu açılır

### Puan
- Her doğru pozisyon = maks_puan / şık_sayısı
- 4 şıklı: 3 doğru → %75 puan
- Kısmi puan desteklenir
